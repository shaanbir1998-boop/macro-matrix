INSTALL MACRO MATRIX

Turn Macro Matrix into an app on your phone or desktop.

If you don’t see this button, use the steps below.

On iPhone (Safari):

  1. Open Macro Matrix in Safari
  2. Tap the Share icon (square with arrow)
  3. Scroll and tap Add to Home Screen
  4. Tap Add

Note: “Add to Home Screen” won’t show inside Instagram/Chrome in-app browsers—open in Safari.

On Android (Chrome):

  1. Open Macro Matrix in Chrome
  2. Tap the ⋮ menu
  3. Tap Install app or Add to Home screen
  4. Confirm Install

On Desktop (Chrome / Edge):

  1. Open the website
  2. Look for the Install icon in the address bar (or browser menu)
  3. Click Install
